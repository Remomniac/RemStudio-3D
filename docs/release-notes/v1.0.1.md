## RemStudio 3D v1.0.1

Turn images and drawings into print-ready 3D wall art with a frame – as STL files for your 3D printer.

### What's new in 1.0.1
- **Fix:** with a circle/oval frame the exported 3D model could have a tiny gap in the mesh (not watertight), which some
  slicers report as an error. Tiny leftover holes are now closed before the mesh is built – the STL also gets smaller.
- Added an automated smoke test (`tests/smoke_test.py`) that checks all frame shapes for watertight meshes.

### Download
- **`RemStudio3D-Setup.exe`** – installer (recommended). Installs for your user account, no admin rights needed.
- **`RemStudio3D-1.0.1-portable.zip`** – no installation: unzip and start `RemStudio3D.exe`.

Requires Windows 10/11 (64-bit). The AI model for background removal is downloaded once on first use (~180 MB).

> **Windows SmartScreen:** Windows may show “Windows protected your PC” on first launch because the installer is not
> digitally signed yet. Click **“More info” → “Run anyway”**. The full source code is available in this repository.

### Features
- AI background removal right after loading an image (runs locally on your PC), with touch-up brushes
- Motif detection for line art, comics, logos, silhouettes and photos
- Frames: rectangle, rounded, circle/oval, hexagon or none
- Loose parts are connected automatically with short bridges; checks for too-thin lines and narrow gaps
- Back plate for two-color printing, hanging holes or loop, rotatable 3D preview
- STL export with automatic splitting for large pieces, plus SVG and PNG
- Real-time, GPU-accelerated preview, dark UI, English and German (switch via **EN/DE**)
